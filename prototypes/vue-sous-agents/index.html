Vue des sous-agents

Six manières de voir, en direct, tous les sous-agents d’une recherche Atlas : qui a lancé qui, qui travaille en ce moment, qui attend une place, qui a échoué. Toutes les options tournent sur la même simulation (commun/simulation.js) : orchestrateur → directeurs de labo → littérature et expérimentateurs, puis graphistes et vérificateur avec recours, six places simultanées. Aucun vrai agent n’est lancé.

Dans chaque option : espace pause, R nouvelle graine, → +30 s, et les paramètres d’URL ?graine=7&vitesse=3&places=6&t=90.

Ce que disent les outils existants

  • Les outils de traçage d’agents (Langfuse, Braintrust, LangSmith, Agent Prism) convergent vers deux vues : l’arbre de spans repliable et la frise temporelle. Tout le monde ne fait que du post-mortem ; presque rien n’est pensé pour le direct.
  • Le flame chart (DevTools) garde le temps, là où le flame graph l’agrège : c’est l’option 2.
  • Le sunburst est déjà utilisé pour les traces distribuées : l’angle = la part d’effort. Option 4.
  • Ce qui manque partout : voir la file d’attente (places limitées), les agents qui attendent leurs enfants sans rien faire, et le moment où un résultat remonte au parent.
